Installing on Windows

Takes under a minute

  1. Run Mditoor-Setup-<version>-Windows-x64.exe.
  2. If SmartScreen appears, choose More info → Run anyway.
  3. Open Mditoor from the Start menu and add your first workspace.

The installer isn't code-signed yet. It's built by a public GitHub Actions workflow from the tagged source, or you can build it yourself.

Build from source

Windows, macOS and Linux

  • Node.js 20+, pnpm, and Rust stable
  • Tauri system dependencies for your OS
bash
git clone https://github.com/ezzdin-atef/mditoor.git
cd mditoor
pnpm install
pnpm tauri build

The installer lands in src-tauri/target/release/bundle/. The first build takes a few minutes.
