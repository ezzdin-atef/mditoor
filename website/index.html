FAQ

Questions about the Markdown & MDX editor

Is Mditoor a free Markdown editor?

Yes. Mditoor is free and open source under the MIT license. There is no account, subscription or telemetry.

Can I edit MDX files with Mditoor?

Yes. Mditoor is a Markdown and MDX editor. It opens .md and .mdx files in place, keeps imports and JSX components intact, and edits frontmatter as a form.

Which blog frameworks does Mditoor support?

Mditoor has presets for Next.js, Astro, Hugo, Jekyll, Docusaurus, Eleventy and Nuxt Content, plus a generic preset for any static site that stores posts as Markdown or MDX files.

Is Mditoor a CMS?

Mditoor works like a local, git-based CMS for static sites. Your posts stay as plain Markdown files in your repository and you publish by committing and pushing from the app.

Does Mditoor compress images?

Yes. Images are resized, compressed and optionally sharpened when you add them, and the asset gallery shows unused images so you can clean them up.

Does Mditoor work offline?

Yes. Mditoor is a local-first desktop app. It only uses the network for git operations and image uploads that you trigger.

Is Mditoor available for Mac and Linux?

A Windows installer is available now. On macOS and Linux you can build Mditoor from source; packaged builds are planned.
